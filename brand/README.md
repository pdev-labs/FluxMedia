# FluxMedia brand assets

The logo kit for FluxMedia. Guidelines: [BRAND_GUIDELINES.md](BRAND_GUIDELINES.md).

## Quick picks

| Use | File |
| --- | --- |
| GitHub avatar / social | `png/fluxmedia-app-icon-512.png` or `svg/fluxmedia-app-icon.svg` |
| README header, light | `svg/fluxmedia-lockup-horizontal-color.svg` |
| README header, dark | `svg/fluxmedia-lockup-horizontal-dark.svg` |
| Square/stacked layout | `svg/fluxmedia-lockup-stacked-color.svg` |
| Symbol only, light | `svg/fluxmedia-symbol-color.svg` |
| Symbol only, dark | `svg/fluxmedia-symbol-dark.svg` |
| One-colour white | `svg/fluxmedia-symbol-white.svg` |
| Small symbol / 16 px | `svg/fluxmedia-symbol-small.svg` |
| Wordmark only | `svg/fluxmedia-wordmark-color.svg` |
| Android launcher | `android/` resources or `png/fluxmedia-app-icon-1024.png` |
| Play Store | `png/fluxmedia-app-icon-store-512.png` |
| Browser tab | `favicon/favicon.ico` + `favicon/site.webmanifest` |

## Contents

```
svg/       vector masters (colour, dark, mono, black, white, small cut, app icon, favicon)
png/       raster exports at 1024/1600/1200 px
favicon/   favicon.ico, PNG favicons, apple-touch-icon, PWA icons, manifest, head snippet
android/   adaptive foreground XML, legacy mipmaps, 1024 logo PNG
```
